# Resume — Mariana Ozaeta

Built in R Markdown for PAF 514, Arizona State University.

**Live version:** https://t00th-blip.github.io/cv/

## Files

- `index.Rmd` — the template
- `positions.csv` — all the resume content, one row per entry
- `parsing_functions.R` — helper functions that turn the CSV into the resume
- `index.html` — the knitted result

To update the resume, edit `positions.csv` and knit `index.Rmd` again.

## Note

This was a course assignment. Entries labeled *ASPIRATIONAL ENTRY* are fictional
examples, not real work history.

Template adapted from [Nick Strayer's CV](https://github.com/nstrayer/cv).
